# Mohan Ashokan - Developer Portfolio 🚀

Welcome to my personal developer portfolio! This repository contains the source code for my portfolio website, showcasing my skills in **Full-Stack Web Development**, **Python Scripting**, **Data Analytics**, and **IoT Projects**.

🌐 **Live Demo:** [https://mohantech03.github.io/mohan-portfolio/public/](https://mohantech03.github.io/mohan-portfolio/public/)

---

## 💻 Tech Stack & Tools

* **Frontend:** HTML5, Modern CSS3 (Glassmorphism & Responsive Grid), JavaScript (ES6+)
* **Backend:** Python (`http.server` & `sqlite3`)
* **Database:** SQLite
* **Contact Integration:** EmailJS Browser SDK (Direct email delivery to `mohantech0304@gmail.com`)
* **Design & Styling:** Custom CSS, Google Fonts (Outfit, Inter)

---

## ✨ Features

- **Single-Page Scrollable Layout:** Smooth scrolling with active navbar section tracking using `IntersectionObserver`.
- **Project Filtering:** Dynamic category filters for Web Development, IoT & Hardware, and Data Visualization.
- **EmailJS Contact Form:** Instant message delivery to email without needing server hosting.
- **Admin Communications Portal:** Password-protected dashboard with Basic Authentication for inspecting contact logs stored in SQLite.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile displays.

## 🛠️ Local Installation & Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/mohantech03/mohan-portfolio.git
   cd mohan-portfolio
   ```

2. **Run the Local Python Server:**
   ```bash
   python server.py
   ```

3. **View in Browser:**
   Open [http://localhost:3000](http://localhost:3000) in your web browser.
